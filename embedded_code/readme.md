# Embedded code

Here is the source code for the tactile sensors, I compiled it with platformio in vs code. It uses the arduino framework, see the .ini file.

In the main file, you can set the name of the sensor, which is usefull if you have multiple of them. Otherwise it is just to flash the sensor and it will start to send out data. If you send 'n' to it will start to print out its name, if you send 's' to it will start to send data again.
