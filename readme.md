# Deformable In-Hand Slip-Aware Tactile Sensor 


This is the material and guides for the paper "Deformable In-Hand Slip-Aware Tactile Sensor with Integrated Velocity Sensing, and Force/Torque and Pressure Map Estimation". You can also find a more popular science presentatin on the entire project https://youtu.be/DqMjxcfm4Ek?si=F0FGEtK1jk1I4O4m

This repo is devided into 3 parts: 
1. build files: this is the files and guide to physically build the sensor 
2. embedded code: this is the code that runs on the sensor
3. code on pc: this is the code on the pc that interfaces with the sensor, it also contains the code for calibrating the sensors. 

A 3D printable version of the gripper used can be found at: https://github.com/Gabrieleenx/Parallel_gripper and the fingers to mount the sensors can be found at "/build_files/fingers_cnc", I CNC them from 6061 aluminium on my own CNC, but they could be ordered from PCBWay.
